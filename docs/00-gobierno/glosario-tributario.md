# GOB-05 — Glosario

Vocabulario del manual y del dominio tributario municipal peruano. **El término del manual manda
sobre el sinónimo culto**: si el manual dice «papeleta», el código dice `Papeleta`.

## Sujetos

| Término | Significado |
|---|---|
| **Contribuyente** | Sujeto pasivo de la obligación tributaria. Tiene **código único** en el sistema, con el que se le enlazan predios, vehículos, papeletas y licencias |
| **Responsable solidario** | Cónyuge, condómino o poseedor que responde de la obligación junto al contribuyente |
| **Inquilino** | Arrendatario registrado en el predio. Interesa para la cobranza de arbitrios |
| **Gestor** | Tercero autorizado a hacer trámites por el contribuyente |
| **Ejecutor coactivo** / **auxiliar coactivo** | Funcionarios que conducen el procedimiento de cobranza coactiva |

## Objetos imponibles

| Término | Significado |
|---|---|
| **Predio** | Unidad inmobiliaria urbana o rústica. Identificada por **código de referencia catastral** |
| **Código de referencia catastral** | `DDPPddSSMMMLLLEEeeppUUU`: departamento, provincia, distrito, sector, manzana, lote, edificación, entrada, piso y unidad catastral |
| **Ficha catastral** | Registro de las características del predio. Cuatro tipos en el manual: única, económica, bienes comunes y rural |
| **Autovalúo** | Valor del predio: terreno (arancel × área) + construcción (valores unitarios − depreciación) + otras instalaciones. Base imponible del predial |
| **Vehículo** | Identificado por placa. Base imponible del patrimonio vehicular durante tres años desde su primera inscripción |

## Tributos y conceptos

| Término | Significado |
|---|---|
| **Impuesto predial** | Anual, sobre el autovalúo. Se paga al contado o en cuatro cuotas trimestrales |
| **Arbitrios** | Tasas por limpieza pública, relleno sanitario, parques y jardines y serenazgo. Mensuales, agrupables |
| **Alcabala** | Impuesto sobre la transferencia de propiedad de un predio |
| **Patrimonio vehicular** | Impuesto anual sobre vehículos, tres ejercicios |
| **Espectáculos públicos no deportivos**, **juegos**, **anuncios** | Los demás impuestos municipales del manual |
| **Tasa** / **derecho** | Cobro por un servicio administrativo. Se cobra en «Caja Tasas» |
| **Insoluto** | Importe original de la deuda, sin recargos |
| **Reajuste** | Actualización del insoluto por índice |
| **Interés** | Interés moratorio devengado |
| **Gasto** / **costas** | Gastos del procedimiento, sobre todo coactivo |
| **Fase** | Etapa de la deuda: ordinaria, valor emitido, coactiva |
| **Cuota** | Fracción periódica de un tributo anual |
| **Alícuota** | Porcentaje que se aplica a la base imponible. **Nunca se le llama «tasa» en el código** |

## Documentos

| Término | Significado |
|---|---|
| **Declaración jurada (HR, PU, PR)** | Hoja de Resumen, Predio Urbano y Predio Rústico. Formatos oficiales que el sistema imprime |
| **Valor** | Documento que formaliza la deuda: **OP** (orden de pago), **RD** (resolución de determinación), **RM** (resolución de multa) |
| **Nota de cargo** | Documento que da de **baja** una deuda (la reduce o la cancela) |
| **Nota de abono** | Documento que da de **alta** una deuda |
| **Papeleta** | Acta de infracción. De **tránsito** o **administrativa** |
| **Notificación administrativa** | Aviso previo a la papeleta administrativa |
| **REC** | Resolución de Ejecución Coactiva. **REC-1** inicia el procedimiento; **REC-2** adopta medida cautelar |
| **Convenio** / **fraccionamiento** | Acuerdo de pago en cuotas. Empieza con un pago inicial («preconvenio») |
| **Quiebre** | Incumplimiento del convenio, que lo deja sin efecto y devuelve las deudas a su estado anterior |
| **Constancia de no adeudo** / **libre de infracciones** | Certificaciones que emite el sistema |

## Procesos

| Término | Significado |
|---|---|
| **Emisión masiva** | Cálculo y generación de deuda de todo el padrón para un ejercicio |
| **Determinación** | Cálculo del importe a pagar de un tributo, periodo y unidad |
| **Cuenta corriente** | Libro de cargos y abonos por contribuyente. En el manual, la «consulta de cuenta corriente» |
| **Fiscalización** | Verificación en campo de lo declarado; termina con transferencia de lo hallado al área de rentas |
| **Omiso** | Contribuyente que no declaró. **Subvaluador**: declaró menos de lo real |
| **Cobranza ordinaria** / **coactiva** | Antes y después del pase a ejecución forzosa |
| **Prescripción** | Extinción de la acción de cobro por transcurso del plazo |
| **Beneficio** | Inafectación, exoneración o descuento: pensionista, gobierno central, monumento histórico, predio rústico, campañas de amnistía |

## Términos técnicos que no se traducen

`repository`, `service`, `controller`, `filter`, `pool`, `endpoint`, `commit`, `rollback`.
Ver la regla de idioma en [CLAUDE.md](../../CLAUDE.md#idioma).
